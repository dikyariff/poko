# Project Context: BlobbyStudio (Blobatar + Playful Soft Neo-Brutalism)

## Ringkasan Diskusi
- **Library Avatar:** [Blobatar](https://www.blobatar.dev/) (`blobatar@2.7.0`) — library open-source zero-dependency untuk membuat avatar SVG geometris yang deterministik dari input string (username, email, ID).
- **Gaya Desain:** **Playful Soft Neo-Brutalism / Tactile Dopamine UI**
  - **Warna:** Cream canvas (`#FFFDF5`), Ink (`#1E1B4B`), Lemon (`#FDE047`), Bubblegum (`#F472B6`), Mint (`#34D399`), Sky (`#38BDF8`), Lavender (`#A78BFA`), Coral (`#FB7185`).
  - **Ciri Visual:** Border gelap tegas (`2px`–`3px`), *hard offset shadow* (`4px 4px 0px #1E1B4B`), sudut membulat (`rounded-2xl` / `rounded-3xl`), dan efek tekan taktil (`btn-tactile`).
  - **Tipografi:** `Fredoka` (display/heading) dan `Plus Jakarta Sans` (body).

## File yang Sudah Dibuat
- `index.html`: Halaman landing interaktif menggunakan **Tailwind CSS CDN** dan **Blobatar ES Module** (`https://cdn.jsdelivr.net/npm/blobatar@2.7.0/+esm` serta `blobatar@2.7.0/expression/+esm`) lengkap dengan live generator, pemilih 6 ekspresi (`idle`, `happy`, `love`, `shy`, `thinking`, `sick`), dan galeri komunitas.
